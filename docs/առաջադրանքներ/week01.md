# Շաբաթ 01–02 — Git և GitHub-ի կարգավորում

## Ամփոփում

Այս երկու շաբաթների ընթացքում ստեղծեցի իմ աշխատանքային միջավայրը՝ GitHub հաշիվ, SSH բանալի, ռեպոզիտորիա, կապեցի այն իմ կայքի կոդի հետ (որը պահում եմ VS Code-ում), և գրեցի կայքի «Իմ մասին» և «Վերջնական պրոյեկտ» բաժինները։

## Քայլեր

### 1. GitHub հաշվի ստեղծում

Ստեղծեցի հաշիվ [github.com](https://github.com) կայքում՝ **AnahitMelqonyan** username-ով։

### 2. SSH բանալու ստեղծում (VS Code տերմինալի միջոցով)

VS Code-ի ներկառուցված տերմինալում գեներացրեցի SSH բանալի.

```bash
ssh-keygen -t ed25519 -C "anahit.melqonyan4565@gmail.com"
```

Բանալին ավելացրեցի ssh-agent-ին.

```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

Հանրային բանալին (public key) պատճենեցի և ավելացրեցի GitHub-ի հաշվում՝ **Settings → SSH and GPG keys → New SSH key**.

```bash
cat ~/.ssh/id_ed25519.pub
```

Ստուգեցի կապը.

```bash
ssh -T git@github.com
```

### 3. Ռեպոզիտորիայի ստեղծում GitHub-ում

GitHub-ում ստեղծեցի նոր ռեպոզիտորիա՝ **my-website** անունով, իմ կայքի համար։

### 4. Կապակցում տեղական կոդի հետ (VS Code)

VS Code-ում պահվող կայքի կոդը կապեցի GitHub ռեպոզիտորիայի հետ.

```bash
git init
git remote add origin git@github.com:AnahitMelqonyan/my-website.git
git add .
git commit -m "Initial commit"
git branch -M main
git push -u origin main
```

### 5. Կայքի բովանդակության լրացում

Թարգմանեցի հայերեն և գրեցի **«Իմ մասին»** (About Me) բաժինը։

Գրեցի նաև **«Վերջնական պրոյեկտ»** (Final Project) բաժինը։

### 6. Փոփոխությունների պահպանում (push) GitHub-ում

Ամեն անգամ, երբ կայքի կոդում փոփոխություն եմ անում (օր. նոր բաժին եմ գրում), պահպանելու համար VS Code-ի տերմինալում գրում եմ հետևյալ հրամանները.

```bash
git add .
git commit -m "Added About Me and Final Project sections"
git push
```

**Ինչ է անում յուրաքանչյուր հրաման.**

- `git add .` — նշում է, որ բոլոր փոփոխված ֆայլերը պատրաստ են պահպանվելու (staging)
- `git commit -m "..."` — ստեղծում է փոփոխության «կետ»՝ համառոտ նկարագրությամբ, թե ինչ է փոխվել
- `git push` — ուղարկում է այդ փոփոխությունները GitHub-ի ռեպոզիտորիա, որտեղ դրանք դառնում են տեսանելի առցանց

Յուրաքանչյուր անգամ commit անելիս `-m`-ից հետո գրվող տեքստը փոխում եմ՝ կախված նրանից, թե կոնկրետ ինչ փոփոխություն եմ անում։

## Խնդիրներ, որոնց բախվեցի

### Խնդիր 1. Ֆայլերը սխալ տեղում էին (ներդրված թղթապանակ)

Իմ առաջին ստեղծած ռեպոզիտորիայում հիմնական template-ի ֆայլերը հայտնվել էին որպես ենթաթղթապանակ իմ `my-website` ֆայլի մեջ, այլ ոչ թե ուղիղ ռեպոզիտորիայի հիմնական մակարդակում։ Սրա պատճառով GitHub-ը error էր տալիս և կայքը չէր բացվում։

**Պատճառը (Root Cause).** GitHub-ից template-ը ներբեռնվել էր որպես ZIP ֆայլ (**Code → Download ZIP**)։ Extract անելուց ստացվում է folder՝ անունով `<repo-name>-main` (օր. `fabfordcs_template-main`)։ Ես տեղափոխել էի **ամբողջ** այդ folder-ը (այլ ոչ թե միայն դրա **պարունակությունը**) իմ `my-website` folder-ի մեջ, ինչի արդյունքում ստեղծվել էր ավելորդ, ներդրված մակարդակ.

```
my-website/            ← ռեպոզիտորիայի root
  └── fabfordcs_template-main/   ← ավելորդ մակարդակ (սխալը)
        ├── mkdocs.yml
        └── docs/
```

GitHub Pages-ը և build համակարգերը սպասում են, որ կարևոր ֆայլերը (`mkdocs.yml`, `docs/` և այլն) գտնվեն **ուղիղ ռեպոզիտորիայի root-ում**, ոչ թե մեկ մակարդակ ավելի խորը, ուստի դրանք չէին գտնում այդ ֆայլերը։

**Լուծում.** Ջնջեցի այդ ռեպոզիտորիան և նորից ստեղծեցի՝ այս անգամ template-ի folder-ի **ներսի ֆայլերը** (ոչ թե ամբողջ folder-ը) տեղադրելով ուղիղ ռեպոզիտորիայի հիմնական մակարդակում։

### Խնդիր 2. Սկավառակում տեղը բավարար չէր

Համակարգչի սկավառակում (disk) տեղը քիչ էր, ինչը նույնպես խնդիրներ էր ստեղծում աշխատանքի ընթացքում։

**Լուծում.** Ջնջեցի տարբեր անհարկի ֆայլեր՝ ազատ տեղ ստեղծելու համար։

## Արդյունք

Կայքի կոդն այժմ վերահսկվում է Git-ով և պահվում է GitHub-ում (github.com/AnahitMelqonyan/my-website)՝ SSH-ի միջոցով միացված։ Հետագա փոփոխությունները կարող եմ push անել ուղղակի VS Code-ից։ Այս երկու շաբաթների ընթացքում ավելացրեցի նաև կայքի «Իմ մասին» և «Վերջնական պրոյեկտ» բաժինները (հայերեն թարգմանությամբ)՝ և push արեցի GitHub-ում, ինչպես նաև լուծեցի մի քանի տեխնիկական խնդիրներ։
