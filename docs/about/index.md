## Իմ ուղին

Ես սկսում եմ իմ ճանապարհը թվային արտադրության ոլորտում։ Այստեղ կարող եք հետևել իմ ուսումնական ընթացքին․ առաջադրանքների կատարմանը, հանդիպած մարտահրավերներին ու դրանց լուծումներին, ինչպես նաև իմ վերջնական նախագծի ստեղծման ողջ պատմությանը։
